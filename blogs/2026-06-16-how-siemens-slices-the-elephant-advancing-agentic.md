Siemens and Google Cloud built Knowledge Fabric, an AI system for automating industrial software modernization using knowledge graphs on Spanner Graph, the Gemini API, and the Agent Development Kit to handle codebases spanning hundreds of millions of lines. The "slicing the elephant" approach breaks refactoring into specialized agent tasks (search, user story creation, architecture impact analysis, task breakdown, and coding), with a pilot reducing dependency analysis time from days to hours.

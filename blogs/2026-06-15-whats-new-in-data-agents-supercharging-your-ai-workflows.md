Google Cloud expands Conversational Analytics across its Data Cloud platform, integrating with BigQuery, Lakehouse, AlloyDB, Spanner, and Cloud SQL. New data agents include the Data Engineering Agent, Data Science Agent, Database Observability Agent, and Looker Dashboard Agent, alongside the Data Agent Kit, Managed MCP Servers for secure database connections, and integration with Gemini Enterprise.
